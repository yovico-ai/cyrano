SSL VPN Rewriter

Browse any site through the rewriting proxy.

Examples

  • example.com — minimal page, good first test
  • news.ycombinator.com — server-rendered, mostly static
  • Wikipedia article — large HTML, lots of links
  • httpbin.org — useful for verifying request rewrites

Target URLs are base64url-encoded into the ?goto= query param. The server fetches and rewrites the response; the bundled /rewriter.js intercepts dynamic URL APIs in the page.
